Bem-vindo ao sistema

Nesta página estão reunidas as funcionalidades previstas para o Sistema de Gestão de Pesquisa de Satisfação.

Funcionalidades

  • Gerenciar categorias de participantes
  • Cadastrar e gerenciar perguntas
  • Gerar códigos anônimos
  • Responder ao questionário
  • Acompanhar a participação
  • Consultar relatórios
Resumo das funcionalidades previstas
Funcionalidade Usuário responsável Objetivo
Categorias Gestor Organizar alunos, professores e colaboradores.
Perguntas Gestor Cadastrar perguntas de múltipla escolha para cada categoria.
Códigos anônimos Gestor Disponibilizar códigos de acesso sem identificar o participante.
Questionário Participante Responder à pesquisa de satisfação.
Participação Gestor Acompanhar a quantidade de respostas recebidas.
Relatórios Gestor Consultar os resultados da pesquisa.

Observação

Nesta etapa, o site utiliza HTML e CSS. As funções de salvar, validar o login e gerar códigos serão implementadas futuramente.
